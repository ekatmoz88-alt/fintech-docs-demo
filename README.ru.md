# Документация Fintech Operations

[English](README.md) | [Русский](README.ru.md)

**Опубликованная документация:** https://ekatmoz88-alt.github.io/fintech-docs-demo/

Техническая документация реального проекта операторской консоли crypto-onramp. Публичные материалы обезличены и описывают пользовательские сценарии, KYC-процессы, операции сотрудников, классификацию данных и аудит.

## Назначение и охват

Проект описывает реальные пользовательские сценарии и внутренние операции операторов: KYC/onboarding, обработку данных, классификацию PII, маскирование, аудит и требования безопасности. Публичная версия обезличена и не содержит клиентских записей или персональных данных.

## Границы

Это реальный проект, представленный в публичном портфолио в обезличенном виде. Клиентские записи, учётные данные и персональная информация не публикуются. Эта страница не утверждает текущий статус эксплуатации исходного сервиса.
