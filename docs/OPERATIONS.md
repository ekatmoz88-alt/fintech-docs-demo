# Редактирование, проверки и публикация

## Локальная работа

Проект преимущественно состоит из Markdown и текстовых материалов. Проверяйте относительные ссылки, согласованность диаграммы с описанием процесса и корректность путей к ресурсам сайта.

## GitHub Pages

Публикация описана в `.github/workflows/pages.yml`. Workflow настроен на изменения `site/**` и самого workflow, а также на ручной запуск. Поэтому изменение только файлов вне этих путей может не запустить публикацию автоматически.

## Release checklist

- [ ] Этапы KYC/onramp согласованы между текстом и схемой.
- [ ] Роли и разрешения операторов описаны однозначно.
- [ ] Правила PII-маскирования и доступа понятны.
- [ ] В audit log не предлагается записывать секреты или полные чувствительные данные.
- [ ] Ссылки и ресурсы сайта открываются.
- [ ] Pages workflow завершился успешно.
- [ ] Опубликованный сайт доступен.

## Диагностика

Проверьте Actions, permissions Pages и наличие артефакта публикации. Сначала исправляйте первую ошибку в журнале, затем повторяйте workflow.
