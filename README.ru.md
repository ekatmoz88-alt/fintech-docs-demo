# Fintech Documentation Demo

[English](README.md) | [Русский](README.ru.md)

**Опубликованная документация:** https://ekatmoz88-alt.github.io/fintech-docs-demo/

Демонстрационный кейс технической документации для вымышленной операторской консоли crypto-onramp.

## Назначение и охват

Проект показывает документирование пользовательских сценариев и внутренних операций операторов: KYC/onboarding, обработку данных, классификацию PII, маскирование, аудит и требования безопасности.

## Основные материалы

- [Crypto onramp flow](flows/04-crypto-onramp.md) — пользовательский и операторский сценарии.
- [PII data classification](security/pii-data-classification.md) — уровни чувствительности, маскирование, доступ и хранение.
- [Audit log specification](security/audit-log-spec.md) — поля аудита, запрещённые данные и сроки хранения.
- [KYC/onramp diagram](diagrams/flow-kyc-onramp.txt) — схема процесса.

## Границы

Это вымышленный демонстрационный проект. Он не описывает действующий финансовый продукт и не содержит реальных клиентских данных или PII.
