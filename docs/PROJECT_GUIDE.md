# Fintech Documentation Demo: обзор проекта

## Назначение

Портфолио-кейс по документации вымышленного crypto-onramp процесса и операторской консоли. Описывает пользовательские этапы, роли операторов, KYC, классификацию PII, маскирование и аудит.

## Основные материалы

- `flows/04-crypto-onramp.md` — сценарий crypto-onramp.
- `security/pii-data-classification.md` — классификация персональных данных.
- `security/audit-log-spec.md` — требования к журналу аудита.
- `diagrams/flow-kyc-onramp.txt` — текстовая схема процесса.
- `site/` — материалы сайта GitHub Pages.
- `.github/workflows/pages.yml` — публикация.

## Принципы

Описывайте роли, входные условия, шаги, исключения и ожидаемый результат. Не включайте реальные персональные данные или секреты.

## Ограничения

Все процессы вымышлены. Материалы не являются юридической или security-консультацией.
